# JMA Motor Finance WebApp

Ready for GitHub Pages / Add to Home Screen.

Files:
- index.html
- style.css
- app.js
- manifest.json
- service-worker.js
- logo.png
- icon-192.png
- icon-512.png

Accounting behavior:
- Daily: shows today's income, expenses, balance, date and time for every transaction.
- Week: Monday-Sunday. Current week is marked Open. Totals are shown in Closed Weeks only after that week ends.
- Month: calendar month. Current month is marked Open. Totals are shown in Closed Months only after the month ends.
- Data is stored locally in the browser/device using localStorage.
- Export button downloads all transactions as CSV.

GitHub Pages:
1. Upload all files to the repository root.
2. Settings -> Pages.
3. Deploy from branch -> main / root.
4. Open the Pages URL on iPhone, then Share -> Add to Home Screen.
